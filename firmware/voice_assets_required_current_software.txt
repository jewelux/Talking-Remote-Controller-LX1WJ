Current speech style in this project

- Numbers are usually spoken as single digits: zero, one, two, three, four, five, six, seven, eight, nine.
- Decimal values are built from digits plus point.
- Short abbreviations are often better spoken as letter sequences:
  USB = u s b
  LSB = l s b
  CW = c w
  CWR = c w r
  WFM = w f m
  SWR = s w r
  RTTY = r t t y
  VFO A/B = vfo + a/b
- Common operating functions are spoken as normal words:
  frequency, mode, lock, tuner, tune, split, rit, repeater, tone, monitor, transceiver, percent, hertz
- Many states are built from a function word plus on/off.
- Profile names are spoken as vendor word plus spoken digits.

- Without these two clips, TX/RX feedback is not fully consistent.

Short conclusion

The current voice style is practical and good:
- digits spoken individually
- abbreviations often spoken letter by letter
- common radio functions as normal words

For the current software, the most important real speech additions are:

voice_rx.wav
