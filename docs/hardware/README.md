# Hardware

> [!IMPORTANT]
> **Planning to build one? Please get in touch first.**
> The hardware is still evolving, so this documentation is deliberately kept minimal and may lag behind the bench.
> Before you order parts or PCBs, [open a build enquiry](https://github.com/jewelux/Talking-Remote-Controller-LX1WJ/issues/new?template=build-enquiry.yml) to get the current state of the board,
> recent changes and build tips. Feedback from builders is very welcome – every question helps to improve the documentation.

| Folder | Board | Status |
|---|---|---|
| [`v1-hamtrc/`](v1-hamtrc/) | HamTRC V1 – original board (12 V input, DC-DC module, SD module) | current |
| `v2-mini-hamtrc/` | HamTRC V2 – Mini-HamTRC, compact 5 V board | in development (`development` branch) |
| [`proto-pcbs/`](proto-pcbs/) | Photos of early prototype boards | archive |

The hardware is evolving. Each board folder contains the schematic and PCB layout as PDF
and a wiring description; V2 also has a bill of materials.
The GPIO mapping is defined in [`firmware/config_pins.h`](../../firmware/config_pins.h).
