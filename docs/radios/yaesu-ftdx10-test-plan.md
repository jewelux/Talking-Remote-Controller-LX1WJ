# Yaesu FTDX10 Family Test Plan

This is the short technical serial test plan for the current **V3.5.8** FTDX10 family block.

Target profiles:

- `PROFILE 11` = `FTDX10`
- `PROFILE 12` = `FTDX101D`
- `PROFILE 13` = `FTDX101MP`


- the intended profile loads
