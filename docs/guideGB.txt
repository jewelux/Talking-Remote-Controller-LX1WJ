Talking Remote Controller LX1WJ – User Guide (English)
=====================================================
Firmware: TalkingRemoteControllerLX1WJ_V1_0.ino
Board: ESP32-S3 DevKitC-1 (N16R8)

Keypad layout (4×4 matrix)
--------------------------
Assumed labeling:
  1  2  3  A
  4  5  6  B
  7  8  9  C
  *  0  #  D

Global keys (work in all banks)
-------------------------------
*  (STAR)
  - Short press: speak the current bank number
  - Long press (HOLD): switch to next bank (Bank 1 → 2 → 3 → 1) and speak it

D  (ENTER)
  - Applies staged actions (e.g. staged volume, staged mode)
  - Confirms frequency entry (see below)

#  (CLEAR / CANCEL)
  - Cancels any active “modal” flow (frequency entry, mode set flow, profile select)
  - Clears any staged command
  - Speaks “OK”

Banks (layers)
--------------
The controller uses 3 banks (layers). Use * (HOLD) to cycle banks.

Bank 1 – Live radio queries + tuning tools
------------------------------------------
NOTE: these keys execute immediately (no ENTER needed).

0  (short press)
  - Query frequency from the radio (FREQ?)
  - If speech is enabled: speaks “frequency” and then the frequency

0  (HOLD)
  - Start frequency entry in kHz
  - Example: type 14070 and press D → sets 14.070 MHz
  - During entry: each digit is spoken for confirmation
  - D applies / # cancels

4  (short press)
  - Query power output (PO?)

7  (short press)
  - Query S-meter once (SM?)

8  (short press)
  - Query SWR once (SWR?)

9  (short press)
  - Query mode once (MODE?)

9  (HOLD)  “MODE SET flow”
  - Starts mode selection. After holding 9, press a digit 1..9 to stage a mode,
    then press D (ENTER) to apply.
  - Mapping (digit → mode):
      1 = LSB
      2 = USB
      3 = CW
      4 = AM
      5 = FM
      6 = DIGI (currently maps to USB)
      7 = RTTY
      8 = CWR
      9 = RTTYR
  - # cancels

A  (volume, direct)
  - Short press: volume down (level -1)
  - HOLD: volume up (level +1)
  - Levels are 0..3

Bank 2 – Reserved
-----------------
Currently reserved in this firmware (no default actions).

Bank 3 – System options / profile selection / volume staging
------------------------------------------------------------
A
  - Short press: speak current profile
  - HOLD: profile select mode
      Press:
        1 = IC-7300 (CI-V)
        2 = Icom 706 (CI-V)
        3 = Icom 706 (RS232)
        4 = Xiegu G106 (CAT)
      # cancels

B
  - Short press: toggle “tuning frequency announcements” ON/OFF
      (so the radio/VFO changes do not always talk)
  - HOLD: speak current state (frequency announcements ON/OFF)

Volume staging (then ENTER to apply)
  - 0 → stage volume level 0 (very low)
  - 7 → stage volume level 1 (low)
  - 8 → stage volume level 2 (medium)
  - 9 → stage volume level 3 (loud)
  - D applies / # cancels

Serial Monitor (Arduino IDE) – Available Commands
-------------------------------------------------
Commands are case-insensitive. End each command with ENTER.

HELP
  - Print command list

QUIET ON | QUIET OFF
  - QUIET ON: suppresses most periodic prints to Serial
  - QUIET OFF: normal prints

SPEECH ON | SPEECH OFF
  - Enables/disables spoken output (speech engine)

LFREQ
  - Show last “live” frequency received via CI-V transceive/broadcast

FREQ?
  - Query frequency (CI-V command 0x03) and print it
  - If speech is enabled: speaks the frequency

MODE?
  - Query current mode (CI-V command 0x04) and print it
  - Speaks the mode if voice clips exist in your build

SM?
  - Query S-meter once and print raw + estimated S value
  - Speaks S value when speech is enabled

SWR?
  - Query SWR once and print raw + estimated SWR
  - Speaks SWR when speech is enabled

PO?
  - Query power output once and print raw value
  - Speaks value when speech is enabled

TEST
  - Plays the voice sample test routine

SAY <digits/point>
  - Speaks digits and '.' as entered
  - Example: SAY 13.207

LISTVOICES
  - Print all available voice clip names

VOICE <name>
  - Play a specific voice clip by name
  - Example: VOICE ok

BANK 1|2|3
  - Set keypad bank directly (and speak it)

Notes / Tips
------------
- If you press a new key while audio is playing, playback is aborted immediately.
- Mode speech depends on which voice clips are compiled in (voice_data.h).
